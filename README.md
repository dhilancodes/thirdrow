# Collaborative Project

This project consists of some basic plots and dataset work with R and serves as an introduction to collaborative workflows with GitHub

## Files

.gitignore - This file tells github what other files in our project folder to ignore. These would be files that are used by the team but are not neccessary for the funcitoning of this repo

README.md - This is the lovely file that you're reading now

plots_un.r - This is an r file that contains code working with a dataset of un memeber states and is the main code of this repo

thirdrow.Rproj - This file contains Rstudio setting so that when this repo is re-loaded into Rstudio it will open up a project with the same settings and configurations as before
